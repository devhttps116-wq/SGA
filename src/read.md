Desenvolvimento da Plataforma Web SGA+

Desenvolva uma plataforma web completa chamada SGA+ (Sistema de Gerenciamento Acadêmico Inteligente).



O SGA+ é uma plataforma SaaS voltada para escolas, cursos técnicos e instituições de ensino, criada para resolver um problema comum: informações acadêmicas espalhadas entre diferentes sistemas, comunicados perdidos, dificuldade em acompanhar notas, frequência, atividades e desempenho dos alunos. O objetivo é reunir tudo em um único ambiente moderno, intuitivo e inteligente, facilitando a vida de alunos, professores, responsáveis e gestores escolares.



Quero que o resultado seja uma versão inicial (MVP Premium). Ela ainda não precisa ter todas as integrações funcionando, porém deve parecer um produto praticamente pronto para lançamento, com identidade visual profissional, componentes reutilizáveis, navegação completa, dashboards ricos e estrutura preparada para crescer.



Não crie apenas telas bonitas. Construa um projeto organizado como um software real, seguindo boas práticas de UX/UI, arquitetura de componentes e responsividade.
